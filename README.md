# 🎓 מערכת ניהול מלגות - Scholarship Management System (PAGI Concept)

מערכת מלאה (Fullstack) להגשת בקשות למלגות וניהולן,  המערכת מאפשרת לסטודנטים להגיש בקשות מורכבות הכוללות מסמכים,
בסיום ההעלה נשלח מייל אישור וכן בעת שינוי סטטוס
 ולמנהלים לסנן ולנהל את הטיפול בבקשות אלו.

---

## 🚀 תכונות עיקריות

### 👨‍🎓 צד סטודנט (Client Side)
* **רישום והתחברות מאובטחת**: מבוסס JWT ועוגיות (Cookies).
* **טופס הגשה דינמי (Stepper)**: חלוקה לארבעה שלבים: פרטים אישיים, פרטי משפחה, פרטי לימודים ופרטי בנק.
* **מנגנון אימות (Validation)**: בדיקות תקינות מחמירות לכל שדה וחובת העלאת מסמכים לפני מעבר לשלב הבא.
* **שמירת טיוטה (Draft)**: אפשרות לשמור את הבקשה באמצע התהליך ולחזור אליה מאוחר יותר.
* **העלאת מסמכים**: תמיכה בהעלאת צילומי תעודת זהות, אישורי לימודים ואישורי ניהול חשבון (Multer).
* **צפייה בסטטוס**: מעקב בזמן אמת אחר מצב הבקשה (בטיפול / אושר / נדחה).

### 👔 צד מנהל (Admin Side)
* **דף ניהול בקשות**: הצגת כל הבקשות הממתינות לטיפול בטבלה מעוצבת.
* **סינון וחיפוש**: יכולת סינון בקשות לפי תעודת זהות, עיר מגורים, שכר לימוד ומספר ילדים.
* **תצוגת פרטים מלאה**: דף ייעודי לכל בקשה המציג את כל הנתונים והמסמכים המצורפים.
* **עדכון סטטוס**: אישור או דחיית בקשות בלחיצת כפתור, המפעילה שליחת מייל אוטומטית למשתמש.

## 🛠 טכנולוגיות

### Frontend
* **React**: ספרייה לפיתוח ממשק המשתמש.
* **Redux Toolkit**: ניהול מצב גלובלי (State Management).
* **React Router**: ניהול ניתובים.
* **SweetAlert2**: הודעות קופצות מעוצבות.

### Backend
* **Node.js & Express**: שרת ה-API.
* **MongoDB & Mongoose**: מסד הנתונים.
* **Multer**: ניהול העלאת קבצים לשרת.
* **Nodemailer**: שליחת מיילים אוטומטיים למשתמשים.
* **JWT & Bcrypt**: אבטחת נתונים ואימות משתמשים.

## ⚙️ הגדרות והרצה

### 1. דרישות מוקדמות
* Node.js מותקן.
* מסד נתונים MongoDB (מקומי או Atlas).

### 2. הגדרת שרת (Backend)
יש ליצור קובץ `.env` בתיקיית השרת עם הפרמטרים הבאים:
```env
PORT=4500
MONGO_URI=your_mongodb_connection_string
SECRET=your_jwt_secret_key
EMAIL_USER=your_gmail_address
EMAIL_PASS=your_app_password
```

**התקנה והרצה:**
```bash
cd backend
npm install
npm start
```

**יצירת מנהל מערכת ראשוני:**
ניתן להריץ את הקובץ `createAdmin.js` ליצירת משתמש ניהולי ראשון:
```bash
node createAdmin.js
```

### 3. הגדרת לקוח (Frontend)
**התקנה והרצה:**
```bash
cd frontend
npm install
npm start
```
